# VIVO Burger Studio

Website for **VIVO Burger Studio** — a premium burger restaurant in Pamplona, Navarra.

Born from competing in [The Champions Burger 2024](https://championsburger.com/) representing Pamplona with the legendary **Douglas** burger.

## Live Site

Open `index.html` in any browser, or deploy to any static host (GitHub Pages, Netlify, Vercel).

## Stack

- Pure HTML5 / CSS3 / Vanilla JavaScript — no build tools, no dependencies
- Google Fonts: Bebas Neue · Barlow Condensed · DM Sans

## Sections

| Section | Description |
|---------|-------------|
| Hero | Full-screen intro with tagline and CTAs |
| Historia | Origin story, Champions Burger 2024, founders |
| Menú | Tabbed menu — starters, burgers, desserts |
| Delivery | Uber Eats & WhatsApp order links |
| Reservas | CoverManager widget + contact info |
| Eventos | Gluten-free buffet, limited edition burgers |
| Galería | Photo grid |
| Contacto | Map, hours, socials |
